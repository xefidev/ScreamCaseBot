⚙️ CUSTOMIZE

Add New Case:
  Edit: src/components/CasesGrid.jsx
  Find: CASES_DATA array
  Add: { id: 11, name: "...", price: ..., ... }

Change Animation Speed:
  Edit: src/components/SpinModal.jsx
  Find: transition={{ duration: 5, ... }}
  Change: duration value (in seconds)

Modify Colors:
  Edit: tailwind.config.js
  Find: theme.extend.colors
  Update: color values

❓ TROUBLESHOOTING

Issue: Port 5173 already in use
Fix:   npm run dev -- --port 3000

Issue: npm install fails
Fix:   npm cache clean --force && npm install

Issue: Cases don't show image
Fix:   Place CaseBlack.png in public/assets/
      Or update path in CasesGrid.jsx

Issue: Animations lag
Fix:   Check browser dev tools
      Try: npm run build && npm run preview
